# One-page landing page template

Clean responsive landing page by JMM Dev Studio. MIT licensed (see `../csv-tidy/LICENSE` for the text; copy it if you reuse this folder alone).

- plain HTML + CSS, no JavaScript, no external fonts, no trackers, no network requests
- responsive from phone to desktop, automatic dark mode, visible keyboard focus, reduced-motion support
- sections: hero, features, pricing, contact, footer

## Use

Open `index.html` in a browser, or serve it: `python3 -m http.server -d .`
Replace the placeholder text, brand name and e-mail address. Change colours in the `:root` block of `style.css`.
